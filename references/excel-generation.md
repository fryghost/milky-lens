# Excel 对比报告生成

Phase 2: 从采集的 JSON 数据生成多工作表 Excel 对比报告。

## 运行命令

```bash
node scripts/create_excel.js
```

输出：`奶粉配方对比分析.xlsx`

---

## 工作表结构

| Sheet | 内容 | 关键特性 |
|-------|------|---------|
| 品牌概览 | 产品基本信息和特色成分 | 黄色高亮基准行 |
| 完整营养成分对比 | 所有营养素 × 所有产品 | 红=高于基准，绿=低于基准，黄=基准列 |
| 配方相似度分析 | 产品相似度排名 | 加权算法，星级评分，优劣分析 |
| 换奶建议 | 分维度推荐 | 最相似/性价比/最全面/进口/同品牌 |
| 价格对比 | 按元/100g排序 | 月均费用估算，性价比评级 |

---

## 核心算法

### 加权相似度

```
营养素权重：
  基础营养（能量/蛋白质/脂肪/碳水等） → 0.3
  矿物质/维生素                        → 0.5
  特色成分（DHA/OPO/乳铁蛋白等）        → 1.0

相似度 = max(0, min(100, 
  100 - 加权平均差异 × 100 
  - 缺失特色成分惩罚（每个 -3%） 
  + 额外特色成分加分（每个 +2%）
))
```

详细定义见 `references/similarity_algorithm.md`。

### 月均费用

```
元/100g = 参考价 / 规格(g) × 100
月均费用 = 元/100g × 30  （按 3kg/月消耗量）
```

## 数据质量检查（必须执行）

生成报告前运行：

```bash
node scripts/validate_products.js
```

检查项：
- 重复产品（相同配方注册号）
- 价格缺失（参考价为 0 或缺失）
- 规格缺失（规格为非数字）
- 营养素缺失（营养素数量 < 20）
