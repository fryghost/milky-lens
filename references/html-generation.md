# 交互式 HTML 报告生成

Phase 3: 从采集的 JSON 数据生成自包含的交互式 HTML 仪表盘。

## 运行命令

```bash
node scripts/generate_report_html.js
```

输出：`reports/奶粉配方对比分析.html`（自包含单文件，约 200KB）

---

## 标题规范

HTML 标题和 `<title>` 标签必须包含段位和日期：

```
奶粉配方对比分析（2段 · 2026年5月）
```

---

## 功能特性

### 5 个 Tab

| Tab | 功能 |
|-----|------|
| 总览 | KPI 卡片 + 品牌柱状图 + TOP5 排名 |
| 相似度分析 | 可排序表格 + 搜索 + 品牌筛选 + 相似度阈值筛选 |
| 价格对比 | 可排序表格 + 搜索 + 品牌筛选 + 价位筛选 |
| 营养对比 | 可搜索下拉框选择 1-5 款产品并排对比 |
| 换奶推荐 | 按 5 个维度分组推荐 |

### 交互特性

- **直接对比按钮**：换奶推荐每行右侧有「直接对比」按钮，点击跳转到营养对比 Tab
- **响应式设计**：适配手机/平板/桌面
- **Dark Mode**：自动跟随系统主题
- **零依赖**：纯 HTML+CSS+JS，无需服务器
