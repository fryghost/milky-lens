# 配方相似度算法详解

对比基准默认为 **惠氏启赋蕴淳 2段**，将其他产品与该基准计算加权相似度得分（0-100）。

## 营养素三级权重

| 类别 | 权重 | 包含的营养素 | 设计理由 |
|------|------|------------|---------|
| 基础营养 | 0.3 | 能量、蛋白质、脂肪、碳水化合物、亚油酸、α-亚麻酸 | 国标严格限定，各产品差异极小，对换奶决策参考价值低 |
| 维生素 | 0.5 | 维生素A/D/E/K/B1/B2/B6/B12/C、烟酸、叶酸、泛酸、生物素 | 国标有范围要求，各产品有一定差异但通常不小 |
| 矿物质 | 0.5 | 钠、钾、铜、镁、铁、锌、锰、钙、磷、碘、氯、硒 | 同上 |
| 特色成分 | 1.0 | DHA、ARA/AA、OPO、乳铁蛋白、核苷酸、CPP、叶黄素、低聚半乳糖/果糖、多聚果糖、HMO、胆碱、肌醇、牛磺酸、左旋肉碱 | 产品差异化的核心维度，对换奶决策最关键 |

## 计算步骤

### Step 1: 加权平均差异

对基准产品含有的每种营养素，计算目标产品的相对偏差，按权重加权：

```
单营养素差异 = |目标值 - 基准值| / 基准值
加权总差异 = Σ(差异 × 权重)  for 所有共有营养素
加权平均差异 = 加权总差异 / 总权重
```

基准值为 0 的营养素跳过。

### Step 2: 缺失惩罚

基准含有但目标产品 **没有** 的特色成分，每项扣 **3 分**：

```
缺失惩罚 = 缺失的特色成分数 × 3
```

只对 PREMIUM_NUTRIENTS 类别生效（特色成分是换奶决策的关键差异点）。

### Step 3: 加分

目标产品有但基准产品 **没有** 的特色成分，每项加 **2 分**：

```
额外加分 = 额外特色成分数 × 2
```

### Step 4: 最终得分

```
原始分 = 100 - 加权平均差异 × 100 - 缺失惩罚 + 额外加分
最终得分 = max(0, min(100, 原始分))
```

## 星级评级

| 分数 | 星级 | 建议 |
|------|------|------|
| ≥ 80 | ★★★★★ | 高度推荐 |
| ≥ 75 | ★★★★☆ | 推荐 |
| ≥ 70 | ★★★☆☆ | 可考虑 |
| ≥ 65 | ★★☆☆☆ | 一般 |
| < 65 | ★☆☆☆☆ | 差异较大 |

## 设计决策

### 为什么基础营养权重低（0.3）？

中国婴幼儿配方奶粉国标（GB 10767-2021）对基础营养（能量、蛋白质、脂肪、碳水）有严格的上下限要求，各品牌产品的数值差异通常在 5% 以内，因此在换奶决策中参考价值较低。

### 为什么特色成分权重高（1.0）？

DHA/ARA/OPO/乳铁蛋白等特色成分各品牌差异极大，是产品定位和定价的关键依据，也是消费者换奶时最关心的维度。给特色成分最高权重，使相似度得分更准确反映消费者关注的差异点。

### 缺失惩罚 vs 额外加分

缺失惩罚（每项 -3）略大于额外加分（每项 +2），体现了"基准产品已有的特色成分缺失时影响更大"的设计意图——换奶时通常不希望丢失已有的关键成分。

## 示例

以飞鹤星飞帆 vs 惠氏启赋蕴淳为例：

```
基准（启赋蕴淳）特色成分: DHA(93), ARA(93), OPO(4.4), 叶黄素(170), 低聚半乳糖(5.29)
目标（星飞帆）特色成分:    DHA(95), ARA(161.5), OPO(4), 叶黄素(210), 低聚半乳糖(3), CPP(40)

DHA:        |95-93|/93    = 0.0215 × 1.0 = 0.0215
ARA:        |161.5-93|/93  = 0.7366 × 1.0 = 0.7366
OPO:        |4-4.4|/4.4    = 0.0909 × 1.0 = 0.0909
叶黄素:     |210-170|/170   = 0.2353 × 1.0 = 0.2353
低聚半乳糖: |3-5.29|/5.29   = 0.4329 × 1.0 = 0.4329

加权总差异 = 0.0215 + 0.7366 + 0.0909 + 0.2353 + 0.4329 = 1.5172
总权重 = 5 × 1.0 = 5
加权平均差异 = 1.5172 / 5 = 0.3034

缺失惩罚 = 0（没有缺失）
加分 = +2（含CPP，基准没有）

最终分 = 100 - 0.3034 × 100 + 2 = 71.66
→ 约 72%，★★★☆☆，可考虑
```
